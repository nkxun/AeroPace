# Explain trade-off

## Steps
1. Restate the result in plain language, in the user's language (English or Hindi).
2. Quote the engine's assumptions, data age and uncertainty.
3. Show the trade-off between time and exposure, not only the benefit.

Follow the [claims policy](references/claims-policy.md).

**Guardrail:** never estimate concentration, dose, probability or travel time yourself. Call the engine and quote what it returns. The engine is planned and not yet built, so the interface below is a proposal.
